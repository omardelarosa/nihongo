# nihongo

A small client-side webapp for studying Japanese kanji. Built with **Vite + React + TypeScript**. Compiles to `public/`.

## Features

- **Flashcards** with on'yomi (音読み, katakana) and kun'yomi (訓読み, hiragana with okurigana) shown separately on the back.
- **Spaced repetition** — Leitner-style streak; intervals **10m → 1d → 3d → 7d → 14d → 30d**. Persisted to `localStorage` (`nihongo:srs:v1`).
- **Multi-select filters** for Section and Theme; **Due only** toggle to focus on cards that are scheduled now.
- Filter selection is also persisted (`nihongo:filters:v1`).

## Develop

```sh
npm install
npm run dev        # Vite dev server with HMR
npm run typecheck
npm run build      # outputs to public/
npm run preview    # serve the built public/ locally
```

The build is configured with `base: './'` so `public/index.html` works when opened directly via `file://`.

## Updating the data

The kanji dataset lives in `data/japanese_kanji_by_section.csv` (source of truth). The typed array consumed by the app is `src/data.ts`, generated by:

```sh
npm run build:data
```

Re-run after editing the CSV.
